# touching-grass

A VSCode extension that guides you to write AI-agent code by hand, so you learn by doing instead of letting AI write it.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on zhongxuank/touching-grass via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
